⚡ StackVault is a decentralized lending protocol built on the Stacks blockchain. It enables users to lock STX as collateral and borrow stablecoins in a trust-minimized, smart contract-governed system. With dynamic interest rates, robust liquidation protection, and seamless integration with SIP-010 stablecoins, StackVault aims to bring Bitcoin-backed DeFi to a global audience — all secured by Bitcoin.
